Student Registration Form with JavaScript Validation

Checks that name, email, and age are all filled in correctly before allowing submission.

Demo

Source

function validateReg(){
  if (!name.value.trim()) return showError('Name is required.');
  if (!email.value.includes('@')) return showError('Enter a valid email.');
  if (age.value < 16) return showError('Age must be 16 or older.');
  return true;
}
