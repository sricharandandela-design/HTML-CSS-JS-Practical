Display Validation Error Messages Dynamically Without Reloading the Page

Errors appear and disappear inline as you type, with no page reload at any point.

Demo

Source

emailInput.oninput = () => {
  errorEl.textContent = (email && !email.includes('@')) ? 'Email must contain @.' : '';
};
/* No form submission or page reload involved — validation happens live, per keystroke. */
