Password Strength Checker

Scores a password live as Weak, Medium, or Strong based on length and character variety.

Demo

Source

let score = 0;
if (pw.length >= 8) score++;
if (/[A-Z]/.test(pw)) score++;
if (/[0-9]/.test(pw)) score++;
if (/[^A-Za-z0-9]/.test(pw)) score++;
