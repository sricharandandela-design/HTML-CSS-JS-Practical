Frequency of Each Element in an Array

Counts how many times each value appears, using a plain object as a tally.

Demo

const freq = {};
items.forEach(item => { freq[item] = (freq[item] || 0) + 1; });
console.log(freq); // e.g. { a: 3, b: 2, c: 1 }
