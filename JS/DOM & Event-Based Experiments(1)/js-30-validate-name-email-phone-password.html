JavaScript Program 30

Validate Name, Email, Phone Number, and Password

Four fields, each checked with its own rule: letters only, valid email shape, 10-digit phone, 8+ char password.

Demo

Source

/^[A-Za-z ]+$/.test(name);                  // letters and spaces only
/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);    // basic email shape
/^\d{10}$/.test(phone);                       // exactly 10 digits
password.length >= 8;                        // minimum length
