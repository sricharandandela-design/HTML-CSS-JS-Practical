Greatest Common Divisor (GCD) of Two Numbers

Uses the Euclidean algorithm: repeatedly replace (a,b) with (b, a mod b) until b is 0.

Demo

Source

function gcd(a, b){
  return b === 0 ? a : gcd(b, a % b); // Euclidean algorithm
}
console.log(gcd(48, 18)); // 6
