JavaScript Program 52

Calculate the Power of a Number

Computed with a loop and compared against JavaScript's built-in ** operator.

Demo

Source

function powerLoop(base, exp){
  let result = 1;
  for (let i = 0; i < exp; i++) result *= base;
  return result;
}
console.log(base ** exp); // built-in exponent operator, same result
