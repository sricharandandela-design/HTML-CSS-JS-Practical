Frequency of Characters in a String

Tallies how many times each character appears, using an object as a counter map.

Demo

Source

const freq = {};
for (const ch of str){ freq[ch] = (freq[ch] || 0) + 1; }
console.log(freq); // e.g. { m:1, i:4, s:4, p:2 }
