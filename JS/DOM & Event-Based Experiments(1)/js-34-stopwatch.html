Stopwatch Using JavaScript

Start, pause, and reset a running stopwatch, displayed in seconds.

Demo

0.0s

Source

let time = 0, interval = null;
function start(){ interval = setInterval(() => { time += 0.1; display.textContent = time.toFixed(1)+'s'; }, 100); }
function pause(){ clearInterval(interval); interval = null; }
