JavaScript Program 55

Remove Duplicate Elements from an Array

Uses a Set, which automatically discards repeated values, then converts back to an array.

Demo

Source

const unique = [...new Set(array)]; // Set stores only unique values automatically
console.log([...new Set([1,2,2,3,4,4,4,5])]); // [1,2,3,4,5]
