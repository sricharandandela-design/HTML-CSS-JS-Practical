Least Common Multiple (LCM) of Two Numbers

Computed from the GCD, using the identity LCM(a,b) = (a*b) / GCD(a,b).

Demo

Source

function lcm(a, b){
  return (a * b) / gcd(a, b);
}
console.log(lcm(4, 6)); // 12
