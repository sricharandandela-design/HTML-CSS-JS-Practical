Spread and Rest Operators

The same ... syntax used two ways: spreading values out, and gathering values in.

Demo

Source

const arr2 = [...arr1, 4, 5];      // spread: unpacks arr1's elements
const obj2 = { ...obj1, z: 3 };    // spread: copies obj1's properties

function sumAll(...nums){          // rest: gathers all arguments into an array
  return nums.reduce((a,b) => a+b, 0);
}
