JavaScript Program 42

Display API Data Dynamically on a Webpage

Fetches a small list from a public API and renders each item as a card in the DOM.

Demo

Source

fetch(apiUrl)
  .then(res => res.json())
  .then(items => {
    items.forEach(item => {
      const card = document.createElement('div');
      card.textContent = item.name;
      list.appendChild(card);
    });
  });
