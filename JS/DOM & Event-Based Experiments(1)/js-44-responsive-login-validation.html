Responsive Login Form with JavaScript Validation

A login form that adapts to narrow screens and validates both fields before allowing submit.

Demo

.rlf{ width:100%; max-width:280px; } /* stays narrow on desktop, full-width on mobile */
function validateLogin(){
  if (!email.includes('@')) return showError('Enter a valid email.');
  if (password.length < 6) return showError('Min 6 characters.');
}
