Change an Image When a Button Is Clicked

Clicking Next cycles the image's src through a small array of URLs.

Demo

Source

const images = ['img1.jpg', 'img2.jpg', 'img3.jpg'];
let index = 0;
function nextImage(){
  index = (index + 1) % images.length;
  imgEl.src = images[index];
}
