JavaScript Program 28

Number Guessing Game

The computer picks a random number 1-50; guess it with feedback of higher/lower.

Demo

Make a guess!

Source

const secret = Math.floor(Math.random() * 50) + 1;
if (guess === secret) win();
else if (guess < secret) hint("Too low");
else hint("Too high");
