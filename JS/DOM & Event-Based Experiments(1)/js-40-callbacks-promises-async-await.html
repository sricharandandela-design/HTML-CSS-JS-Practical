JavaScript Program 40

Callbacks, Promises, and Async/Await

The same delayed operation written three ways, showing how async code evolved.

Demo

Click Run and wait ~1 second...

Source

// 1. Callback style
function delayedValue(callback){ setTimeout(() => callback(42), 800); }

// 2. Promise style
function delayedPromise(){ return new Promise(resolve => setTimeout(() => resolve(42), 800)); }

// 3. Async/await style (cleanest to read)
async function run(){
  const result = await delayedPromise();
  console.log(result);
}
