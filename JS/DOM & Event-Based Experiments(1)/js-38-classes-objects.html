Classes and Objects

An ES6 class with a constructor and a method, then an instance created from it.

Demo

Source

class Book{
  constructor(title, author){ this.title = title; this.author = author; }
  describe(){ return `"${this.title}" by ${this.author}`; }
}

const b = new Book("Atomic Habits", "James Clear");
console.log(b.describe());
