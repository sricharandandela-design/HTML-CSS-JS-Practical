Inheritance in JavaScript

A subclass extends a base class with extends and super(), reusing and overriding behaviour.

Demo

Source

class Animal{
  constructor(name){ this.name = name; }
  speak(){ return `${this.name} makes a sound.`; }
}
class Dog extends Animal{
  speak(){ return `${this.name} barks.`; } // overrides Animal's speak()
}
