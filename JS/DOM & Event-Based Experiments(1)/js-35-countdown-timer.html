Countdown Timer Using JavaScript

Counts down from a chosen number of seconds to zero.

Demo

--

Source

let remaining = startValue;
const interval = setInterval(() => {
  remaining--;
  display.textContent = remaining >= 0 ? remaining + 's' : "Time's up!";
  if (remaining < 0) clearInterval(interval);
}, 1000);
