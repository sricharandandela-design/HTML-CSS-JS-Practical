Count the Number of Digits in a Number

Counts digits by repeated division, and shows the string-length shortcut too.

Demo

Source

function countDigits(n){
  let count = 0, num = Math.abs(n);
  while (num > 0){ count++; num = Math.floor(num / 10); }
  return count;
}
String(Math.abs(n)).length; // shortcut using string length
