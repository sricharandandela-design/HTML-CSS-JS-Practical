Theme Switcher (Light/Dark Mode) Using localStorage

Remembers the chosen theme in localStorage so it's still applied after a page reload.

Demo

Current theme is applied and saved for next time.

Source

function setTheme(theme){
  applyStyles(theme);
  localStorage.setItem('theme', theme);
}
const saved = localStorage.getItem('theme');
if (saved) setTheme(saved); // restores the theme on page load
