Shopping Cart Using localStorage

Adds items to a cart array stored as JSON in localStorage, so it survives a page refresh.

Demo

Source

const cart = JSON.parse(localStorage.getItem('cart') || '[]');
cart.push(item);
localStorage.setItem('cart', JSON.stringify(cart)); // arrays/objects need JSON.stringify
