BMI Calculator

Computes Body Mass Index from height and weight, and labels the result category.

Demo

Source

const bmi = weight / (height * height);
const category = bmi < 18.5 ? 'Underweight' : bmi < 25 ? 'Normal' : bmi < 30 ? 'Overweight' : 'Obese';
