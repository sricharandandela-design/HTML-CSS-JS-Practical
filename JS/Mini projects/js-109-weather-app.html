Weather Application Using an API

Fetches live weather for a typed-in city using the free Open-Meteo API (no key required).

Demo

Enter a city and click the button.

Source

const geo = await fetch(`https://geocoding-api.open-meteo.com/v1/search?name=${city}`);
const { latitude, longitude } = (await geo.json()).results[0];
const weather = await fetch(`https://api.open-meteo.com/v1/forecast?latitude=${latitude}&longitude=${longitude}&current_weather=true`);
console.log((await weather.json()).current_weather);
