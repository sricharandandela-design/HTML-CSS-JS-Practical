Number Guessing Game (Mini Project)

Builds on program 28 by limiting the player to 5 attempts and tracking attempts remaining.

Demo

You have 5 attempts. Good luck!

Source

let attempts = 5;
if (guess === secret) win();
else if (--attempts === 0) gameOver();
else hint(guess < secret ? "Too low" : "Too high");
