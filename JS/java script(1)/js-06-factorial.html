Find the Factorial of a Number

Computed iteratively with a for loop.

Demo

Output will appear here.

Source

function factorial(n){
  let result = 1;
  for (let i = 2; i <= n; i++) result *= i;
  return result;
}

console.log(factorial(6)); // 720
