Find the Sum of Digits of a Number

Repeatedly extracts the last digit with modulus and adds it to a running total.

Demo

Output will appear here.

Source

function sumOfDigits(n){
  let num = Math.abs(n);
  let sum = 0;
  while (num > 0){
    sum += num % 10;
    num = Math.floor(num / 10);
  }
  return sum;
}

console.log(sumOfDigits(4938)); // 24
