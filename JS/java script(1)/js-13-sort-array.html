JavaScript Program 13

Sort an Array

Uses Array.prototype.sort with a numeric comparator, since the default sort compares as text.

Demo

Output will appear here.

Source

const numbers = [40, 5, 100, 25, 3];

// A numeric comparator is required - without it, sort() compares as strings
const ascending = [...numbers].sort((a, b) => a - b);
const descending = [...numbers].sort((a, b) => b - a);

console.log(ascending);  // [3, 5, 25, 40, 100]
console.log(descending); // [100, 40, 25, 5, 3]
