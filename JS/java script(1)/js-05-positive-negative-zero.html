Check Whether a Number Is Positive, Negative or Zero

A simple three-way if/else chain.

Demo

Output will appear here.

Source

function classify(n){
  if (n > 0) return "Positive";
  if (n < 0) return "Negative";
  return "Zero";
}

console.log(classify(-8)); // Negative
