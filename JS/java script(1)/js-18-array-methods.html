JavaScript Program 18

Demonstrate Arrays and Array Methods

map, filter, reduce and find applied to a small list of numbers.

Demo

Output will appear here.

Source

const nums = [1, 2, 3, 4, 5, 6, 7, 8];

nums.map(n => n * 2);            // [2,4,6,8,10,12,14,16]
nums.filter(n => n % 2 === 0);   // [2,4,6,8]
nums.reduce((a, b) => a + b, 0); // 36
nums.find(n => n > 5);           // 6
