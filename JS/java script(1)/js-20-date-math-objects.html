JavaScript Program 20

Demonstrate Date and Math Objects

Reads the current date/time from the built-in Date object, and runs a few Math helper methods.

Demo

Output will appear here.

Source

const now = new Date();
now.toDateString();     // e.g. "Wed Sep 16 2026"
now.getFullYear();      // e.g. 2026
now.getHours();         // current hour, 0-23

Math.max(4, 19, 7);     // 19
Math.sqrt(144);         // 12
Math.round(4.6);        // 5
Math.random();          // a fresh decimal between 0 and 1 each call
