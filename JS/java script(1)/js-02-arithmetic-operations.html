JavaScript Program 02

Perform Arithmetic Operations

Takes two numbers and shows the result of +, -, *, / and % (modulus).

Demo

Output will appear here.

Source

function arithmetic(a, b){
  return {
    sum: a + b,
    difference: a - b,
    product: a * b,
    quotient: a / b,
    remainder: a % b
  };
}

console.log(arithmetic(12, 5));
// { sum: 17, difference: 7, product: 60, quotient: 2.4, remainder: 2 }
