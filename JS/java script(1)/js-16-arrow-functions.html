Demonstrate Arrow Functions

The same operations written as arrow functions, including the implicit-return short form.

Demo

Output will appear here.

Source

const add = (a, b) => a + b;                     // implicit return
const shout = text => text.toUpperCase() + "!";  // single param, no parentheses needed
const describe = (name, age) => {                // block body needs an explicit return
  return `${name} is ${age} years old`;
};

console.log(add(4, 7));            // 11
console.log(shout("hi"));          // HI!
console.log(describe("Sam", 21));  // Sam is 21 years old
