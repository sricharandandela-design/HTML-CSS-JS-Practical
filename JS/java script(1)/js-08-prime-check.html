Check Whether a Number Is Prime

Tests divisibility only up to the square root of the number, for an efficient check.

Demo

Output will appear here.

Source

function isPrime(n){
  if (n < 2) return false;
  for (let i = 2; i <= Math.sqrt(n); i++){
    if (n % i === 0) return false;
  }
  return true;
}

console.log(isPrime(29)); // true
