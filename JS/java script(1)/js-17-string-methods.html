Demonstrate Strings and String Methods

Common string methods applied to whatever text you type in.

const s = "  Hello JavaScript World  ";

s.length;                          // 27
s.trim();                          // "Hello JavaScript World"
s.toUpperCase();                   // "  HELLO JAVASCRIPT WORLD  "
s.includes("Script");              // true
s.replace("World", "Students");    // "  Hello JavaScript Students  "
s.trim().split(" ");               // ["Hello", "JavaScript", "World"]
