Find the Largest of Three Numbers

Compares three numbers using Math.max (the everyday approach) and shows the equivalent if/else logic in the source.

Demo

Output will appear here.

Source

function largestOfThree(a, b, c){
  let largest = a;
  if (b > largest) largest = b;
  if (c > largest) largest = c;
  return largest;
}

console.log(largestOfThree(14, 27, 9)); // 27
