# Test Supabase REST APIs using Postman.

## Steps
1. Open the Supabase dashboard and create/select your project.
2. Use the SQL Editor or the relevant dashboard panel for this experiment.
3. Replace placeholder project values with your own project details.
4. Test the result and record the output in your practical record.
