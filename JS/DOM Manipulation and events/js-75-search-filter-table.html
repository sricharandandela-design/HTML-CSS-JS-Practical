Search/Filter Table Records

Typing in the search box hides table rows that don't match, in real time.

Source

searchInput.oninput = () => {
  const term = searchInput.value.toLowerCase();
  rows.forEach(row => {
    row.style.display = row.textContent.toLowerCase().includes(term) ? '' : 'none';
  });
};
