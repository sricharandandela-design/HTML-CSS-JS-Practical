Event Bubbling and Event Capturing

Clicking the inner box shows both phases firing: capturing (outer to inner) then bubbling (inner to outer).

outer.addEventListener('click', () => log('capturing'), true); // true = capture phase

outer.addEventListener('click', () => log('bubbling'));               // default = bubble phase
