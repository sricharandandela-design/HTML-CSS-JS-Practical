JavaScript Program 79

Dependent Dropdown: Country &rarr; State &rarr; City

Choosing a country repopulates the state dropdown with only that country's states.

Demo

Source

const statesByCountry = { india: [...], usa: [...] };
countrySelect.onchange = () => {
  stateSelect.innerHTML = '';
  statesByCountry[countrySelect.value].forEach(state => {
    stateSelect.appendChild(new Option(state));
  });
};
