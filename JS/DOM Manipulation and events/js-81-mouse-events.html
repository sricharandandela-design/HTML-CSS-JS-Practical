JavaScript Program 81

Demonstrate Mouse Events

A box reports mouseenter, mouseleave, and mousemove coordinates.

Demo

Move your mouse over this box

Source

box.addEventListener('mouseenter', () => console.log('entered'));
box.addEventListener('mouseleave', () => console.log('left'));
box.addEventListener('mousemove', e => console.log(e.offsetX, e.offsetY));
