Keyboard-controlled Webpage/Game

Use the arrow keys to move a square around inside its box.

Demo

Click the box, then use arrow keys.

Source

gameArea.addEventListener('keydown', e => {
  if (e.key === 'ArrowUp') y -= 10;
  if (e.key === 'ArrowDown') y += 10;
  player.style.top = y + 'px';
});
