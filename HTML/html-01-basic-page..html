This is a normal paragraph. Paragraphs are block-level elements, so the browser automatically adds space above and below them. A paragraph can hold as much text as needed and it will wrap naturally to fill the width of its container.

Sometimes a line needs to break at an exact point instead of wrapping naturally — for example, in an address or a short poem.
This line starts right below the one above it,
and this line starts right below that one,
all inside a single paragraph, using the <br> tag.
