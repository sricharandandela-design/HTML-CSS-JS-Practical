HTML Program 02

Ordered, Unordered and Description Lists

Shows the three list types HTML provides and when each one is the right choice.

Demo

Unordered list — items with no required sequence

  • HTML — structure
  • CSS — presentation
  • JavaScript — behaviour

Ordered list — steps that must happen in sequence

  1. Write the HTML structure
  2. Style it with CSS
  3. Add interactivity with JavaScript
  4. Test in the browser

Description list — terms paired with their definitions

HTML
HyperText Markup Language, used to structure content on the web.
CSS
Cascading Style Sheets, used to control layout and appearance.
JavaScript
A programming language used to make web pages interactive.
