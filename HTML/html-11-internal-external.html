Internal and External CSS Styling

The same paragraph styled three ways: inline, internal (a <style> block) and external (this project's own stylesheet.css).

Demo

This paragraph is styled with an inline style attribute directly on the tag.

This paragraph is styled by an internal <style> block declared in this page's own <head>.

This paragraph uses only the project's external stylesheet, assets/css/style.css, linked once and shared by every page.

Source

<!-- 1. Inline: style="" on the element itself -->
<p style="color:#B14B3F; font-style:italic;">Inline styling</p>

<!-- 2. Internal: a <style> block in the page's own <head> -->
<style>
  .internal-demo{ color: teal; border-left: 4px solid orange; padding: 0.6rem 1rem; }
</style>
<p class="internal-demo">Internal styling</p>

<!-- 3. External: rules kept in a separate .css file and linked -->
<link rel="stylesheet" href="assets/css/style.css">
<p>External styling</p>
