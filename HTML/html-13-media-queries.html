Responsive Webpage Using Media Queries

Resize the browser window (or view on a phone) to see these three boxes reflow from a row into a stack.

Demo

Box 1
Box 2
Box 3

Above 640px wide the boxes sit in a green row; at 640px or narrower the media query switches them to an amber column.

Source

.mq-row{ display:flex; gap:1rem; }
.mq-box{ flex:1; background:#3F6C5D; color:#fff; padding:1rem; text-align:center; }

@media (max-width: 640px){
  .mq-row{ flex-direction: column; }
  .mq-box{ background:#E8A33D; color:#1A2332; }
}
