HTML Program 07

Frames and Iframes

The classic <frameset> is obsolete in HTML5; <iframe> is the modern replacement for embedding one page inside another.

Demo

The iframe below embeds this project's own home page inside the current page:

Note: the old <frameset>/<frame> tags are not supported in HTML5. Whenever a page needs to embed another document, use <iframe> instead.

Source

<!-- Modern HTML5 approach -->
<iframe src="page-to-embed.html" title="Embedded page" width="100%" height="260"></iframe>

<!-- Obsolete HTML4 approach, shown for reference only, not supported in HTML5 -->
