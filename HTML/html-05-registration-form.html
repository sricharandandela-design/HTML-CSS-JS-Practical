HTML Program 05

Student Registration Form

A registration form built from text, email, radio, checkbox, select and textarea controls, with basic HTML validation.

Demo

Fill in the form and press Register.

Source

<form onsubmit="event.preventDefault(); handleRegister();">
  <input type="text" name="fullName" required minlength="3">
  <input type="email" name="email" required>
  <input type="radio" name="gender" value="female" checked> Female
  <input type="radio" name="gender" value="male"> Male
  <select name="course">
    <option>B.Sc Computer Science</option>
    <option>B.C.A</option>
  </select>
  <input type="checkbox" name="hostel"> Requires hostel accommodation
  <textarea name="note" rows="3"></textarea>
  <button type="submit">Register</button>
</form>
