Selectors, Colours, Fonts, Margins, Padding and Borders

Element, class, ID and descendant selectors, plus the CSS box model in action.

Demo

Styled by the element selector p (monospace font).

Styled by the class selector .highlight.

Styled by the ID selector #unique-box — this box shows margin (space outside), a border, and padding (space inside) all at once.
  • Styled by the descendant selector ul li

Source

p{ font-family: monospace; }              /* element selector   */
.highlight{ color: #E8A33D; font-weight:600; } /* class selector    */
#unique-box{                                   /* ID selector       */
  border: 3px solid #3F6C5D;
  margin: 1rem 0;      /* space outside the border */
  padding: 1rem 1.4rem; /* space inside the border  */
}
ul li{ color: #3F6C5D; }                       /* descendant selector */
