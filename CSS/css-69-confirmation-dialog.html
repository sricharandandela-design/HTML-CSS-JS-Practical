CSS Program 69

Confirmation Dialog Component

A destructive-action confirmation, styled to make the risk clear before the user commits.

Demo

Delete this project?

This cannot be undone. All files and history will be permanently removed.

Source

<dialog id="confirmEl">
  <h3 style="color:#B14B3F;">Delete this project?</h3>
  <p>This cannot be undone.</p>
  <button onclick="confirmEl.close()">Cancel</button>
  <button style="background:#B14B3F;" onclick="confirmEl.close()">Yes, delete</button>
</dialog>
