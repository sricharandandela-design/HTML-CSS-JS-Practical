Universal, Element, Class, ID, Attribute, and Grouping Selectors

Six ways to target elements, from broadest to most specific.

Demo

Selector demo

Element selector p gives every paragraph a mono font.

Class selector .tag colours just this line.

ID selector #one targets this exact box only.
Grouped heading (h4, h5 share one rule)

Source

*{ box-sizing: border-box; }             /* universal selector   */
p{ font-family: monospace; }              /* element selector     */
.tag{ color: #E8A33D; }                   /* class selector       */
#one{ border: 2px solid #3F6C5D; }        /* ID selector          */
input[type="email"]{ border-color:#E8A33D; } /* attribute selector */
h4, h5{ color: #3F6C5D; }                 /* grouping selector    */
