2D Transformations: Rotate, Scale, Translate, and Skew

Four transform functions, each moving or reshaping a box without affecting the layout around it.

.scale    { transform: scale(1.3); }
.translate{ transform: translate(10px, 10px); }
.skew     { transform: skew(-12deg); }
