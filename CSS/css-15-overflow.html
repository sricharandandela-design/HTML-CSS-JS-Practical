CSS Program 15

Overflow, Overflow-x, and Overflow-y Properties

A box with more content than fits, shown with three different overflow behaviours.

Demo

overflow: hidden — extra content is clipped and simply not shown, with no scrollbar at all, no matter how much text you add here.
overflow: scroll — always shows scrollbars, even if the content fits, so you can scroll to read this longer line of text.
overflow-x: auto — a horizontal scrollbar appears only because this single line is too wide to fit in the box.

Source

.clip   { overflow: hidden; }               /* extra content is cut off      */
.scroll { overflow: scroll; }               /* scrollbars always shown       */
.auto-x { overflow-x: auto; overflow-y: hidden; } /* scrollbar only if needed */
