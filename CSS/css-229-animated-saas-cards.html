Animated SaaS Cards and Components

Cards that fade and rise into view using a CSS animation on page load.

Source

@keyframes cardIn{ from{ opacity:0; transform:translateY(12px); } to{ opacity:1; transform:translateY(0); } }
.card{ animation: cardIn 0.5s ease forwards; }
.card:nth-child(2){ animation-delay:0.1s; } /* staggered entrance */
