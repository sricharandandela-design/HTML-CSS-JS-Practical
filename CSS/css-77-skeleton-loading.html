CSS Program 77

Skeleton-loading Component

Grey placeholder shapes that shimmer while real content is still being fetched.

Demo

Source

.skeleton{
  background: linear-gradient(90deg, #E4E2D8 25%, #F1EFE6 37%, #E4E2D8 63%);
  background-size: 400% 100%;
  animation: shimmer 1.4s ease infinite;
}
@keyframes shimmer{
  0%   { background-position: 100% 50%; }
  100% { background-position: 0 50%; }
}
