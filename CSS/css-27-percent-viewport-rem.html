CSS Program 27

Width/Height Percentages, Viewport Units, and Rem Units

Three sizing strategies compared: relative to the parent, relative to the viewport, and relative to the root font size.

Demo

width: 50% of parent
width: 40vw (40% of viewport width)
width: 15rem (15 × root font size)

Source

.half-parent{ width: 50%; }   /* relative to the containing element   */
.two-fifths-vw{ width: 40vw; } /* relative to the browser viewport width */
.fixed-rem{ width: 15rem; }    /* relative to the root <html> font-size  */
