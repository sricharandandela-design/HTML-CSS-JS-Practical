CSS Program 18

CSS Variables and Custom Properties

One variable, declared once on :root, reused by three unrelated elements — change it in one place, everything updates.

Demo

Text colour uses --brand

Background uses --brand
Border uses --brand too

Source

:root{ --brand: #3F6C5D; }   /* declared once */

.a{ color: var(--brand); }
.b{ background: var(--brand); }
.c{ border: 3px solid var(--brand); }
/* change --brand in one place and all three update */
