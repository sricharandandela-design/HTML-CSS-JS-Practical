CSS Program 11

Width, Height, Min-width, Max-width, Min-height, and Max-height

A box constrained so it never shrinks below or grows past chosen limits — try resizing the browser window.

Demo

This box has width:60%, but is clamped between min-width:180px and max-width:420px, so it never gets too small on narrow screens or too wide on huge ones. Resize your browser to see it stop growing/shrinking.

Source

.limit-box{
  width: 60%;
  min-width: 180px;
  max-width: 420px;
  min-height: 60px;
  max-height: 160px;
  overflow: auto; /* scrolls if content exceeds max-height */
}
