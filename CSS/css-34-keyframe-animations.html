CSS Program 34

CSS Keyframe Animations

A looping @keyframes animation that moves and recolours a box automatically, with no JavaScript.

Demo

looping

Source

@keyframes float-glow{
  0%   { transform: translateY(0);     background: #3F6C5D; }
  50%  { transform: translateY(-14px); background: #E8A33D; }
  100% { transform: translateY(0);     background: #3F6C5D; }
}

.box{ animation: float-glow 2s ease-in-out infinite; }
