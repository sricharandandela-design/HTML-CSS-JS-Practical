CSS Program 05

Background Images, Colors, Positioning, Sizing, Repeat, and Attachment

Every background-* property applied to the same box, one property at a time.

Demo

background-color
background-repeat + size (tiled)
background-size: cover + position: center
background-attachment: fixed

Source

.bg-color{ background-color: #3F6C5D; }

.bg-tiled{
  background-image: url('pattern.png');
  background-repeat: repeat;
  background-size: 80px;
}

.bg-cover{
  background-image: url('photo.jpg');
  background-size: cover;
  background-position: center;
}

.bg-fixed{
  background-image: url('photo.jpg');
  background-attachment: fixed; /* stays put while the page scrolls */
}
