CSS Program 33

3D Transformations and Perspective Effects

A card that tilts in 3D space using rotateX/rotateY, viewed through a perspective on its container.

Demo

hover to tilt in 3D

The parent's perspective: 600px gives the rotated card depth instead of looking flat.

Source

.container{ perspective: 600px; } /* sets the "camera distance" for children */

.card{ transition: transform 0.4s ease; }
.card:hover{ transform: rotateY(25deg) rotateX(10deg); } /* tilts in 3D space */
