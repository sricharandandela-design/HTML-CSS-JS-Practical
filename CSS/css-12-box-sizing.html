CSS Program 12

The Box-sizing Property: Content-box and Border-box

Two boxes with identical width/padding/border — one grows past its set width (content-box), one doesn't (border-box).

Demo

content-box: renders wider than 200px (padding+border are added on top)
border-box: stays exactly 200px total (padding+border eat into it)

Source

.content-box{
  box-sizing: content-box;  /* default: width = content only        */
  width: 200px; padding: 20px; border: 6px solid #3F6C5D;
  /* rendered width = 200 + 40(padding) + 12(border) = 252px */
}

.border-box{
  box-sizing: border-box;   /* width INCLUDES padding + border      */
  width: 200px; padding: 20px; border: 6px solid #3F6C5D;
  /* rendered width stays exactly 200px */
}
