CSS Program 04

CSS Colors for Text, Backgrounds, Borders, and UI Elements

The same colour value written four ways: named, hex, rgb() and hsl().

Demo

named: teal
hex: #3F6C5D
rgb(63,108,93)
hsl(155,26%,33%)

Text colour, and a border colour, set independently of the background.

Source

.text{ color: #B14B3F; }
.bg-named{ background: teal; }
.bg-hex{ background: #3F6C5D; }
.bg-rgb{ background: rgb(63, 108, 93); }
.bg-hsl{ background: hsl(155, 26%, 33%); }
.border{ border: 2px solid #E8A33D; }
