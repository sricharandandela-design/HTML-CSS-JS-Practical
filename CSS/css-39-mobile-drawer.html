CSS Program 39

Mobile Sidebar Navigation Drawer

A sidebar that slides in from off-screen when opened, and slides back out when closed.

Demo

Menu

Dashboard · Projects · Settings

Source

.drawer{
  position:absolute; left:0; top:0; height:100%; width:200px;
  transform: translateX(-100%);      /* hidden off-screen by default */
  transition: transform 0.3s ease;
}
.drawer.open{ transform: translateX(0); } /* slides fully into view */
