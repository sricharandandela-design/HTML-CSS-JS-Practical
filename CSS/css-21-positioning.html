CSS Program 21

Static, Relative, Absolute, Fixed, and Sticky Positioning

Five positioning schemes; scroll the box on the right to see 'sticky' and 'fixed' in action.

Demo

static: normal flow (default)
relative: nudged 6px down, 10px right from where it would sit
sticky: sticks to the top of this box once you scroll past it
scroll me — 300px of filler content
absolute: pinned to this container's corner

Source

.static  { position: static; }                    /* default flow                */
.relative{ position: relative; top: 6px; left: 10px; } /* offset from its own spot */
.absolute{ position: absolute; bottom: 6px; right: 6px; } /* relative to nearest positioned ancestor */
.fixed   { position: fixed; top: 0; right: 0; }    /* relative to the viewport, ignores scroll */
.sticky  { position: sticky; top: 0; }             /* static until scrolled past, then fixed  */
