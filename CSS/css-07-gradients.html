Linear and Radial CSS Gradients

Two gradient functions: linear-gradient (direction-based) and radial-gradient (centre-out).

Demo

linear-gradient(90deg, ink, pine)
linear-gradient(135deg, amber, danger)
radial-gradient(circle, pine, ink)

Source

.linear-h{ background: linear-gradient(90deg, #1A2332, #3F6C5D); }
.linear-d{ background: linear-gradient(135deg, #E8A33D, #B14B3F); }
.radial  { background: radial-gradient(circle, #3F6C5D, #1A2332); }
