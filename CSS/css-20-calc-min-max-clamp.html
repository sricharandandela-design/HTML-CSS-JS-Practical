CSS Program 20

The calc(), min(), max(), and clamp() Functions

Four math-aware CSS functions used to size things relative to their container.

Demo

width: calc(100% - 40px)
width: min(80%, 300px) — never wider than 300px
width: max(40%, 220px) — never narrower than 220px

font-size: clamp(1rem, 2.5vw, 1.8rem) — resize the window to see this text scale smoothly between its floor and ceiling.

Source

.calc { width: calc(100% - 40px); }        /* subtract a fixed gutter from 100% */
.min  { width: min(80%, 300px); }          /* the SMALLER of the two              */
.max  { width: max(40%, 220px); }          /* the LARGER of the two                */
.fluid{ font-size: clamp(1rem, 2.5vw, 1.8rem); } /* fluid, but bounded both ends  */
