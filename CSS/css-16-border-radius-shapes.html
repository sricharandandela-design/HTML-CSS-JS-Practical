CSS Program 16

Border-radius for Rounded Cards, Circles, Pills, and Custom Shapes

One property, four very different looks depending on the values and the box's aspect ratio.

Demo

card: 10px
circle: 50%
pill: 999px
blob

Source

.card  { border-radius: 10px; }
.circle{ width: 80px; height: 80px; border-radius: 50%; }   /* equal w/h + 50% = circle */
.pill  { border-radius: 999px; }                             /* radius bigger than half height */
.blob  { border-radius: 50% 10% 50% 10%; }                   /* different value per corner */
