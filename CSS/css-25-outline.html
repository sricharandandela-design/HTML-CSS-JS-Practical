CSS Program 25

CSS Outline and Outline-offset Properties

Outline draws outside the border box without affecting layout — click the button to see its focus outline.

Demo

outline: 3px solid
outline-offset: 6px

Source

.box{ outline: 3px solid #E8A33D; }                 /* doesn't affect layout, unlike border */
.offset-box{ outline: 3px solid #3F6C5D; outline-offset: 6px; } /* gap between border and outline */
button:focus-visible{ outline: 3px solid #E8A33D; outline-offset: 2px; }
