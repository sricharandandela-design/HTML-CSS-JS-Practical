CSS Program 13

Display Properties: block, inline, inline-block, flex, grid, and none

The same six <span> elements, each given a different display value.

Demo

Source

.a{ display: block; }        /* own line, full width available   */
.b{ display: inline; }       /* flows inside a line of text      */
.c{ display: inline-block; } /* flows inline but accepts width   */
.d{ display: none; }         /* removed from layout entirely     */
.e{ display: flex; }         /* children laid out in a flex row  */
.f{ display: grid; grid-template-columns: 1fr 1fr 1fr; }
