CSS Program 29

Object-fit and Object-position Properties

The same wide image placed in a square frame three different ways.

Demo

Left to right: fill (stretched, distorted), cover (cropped to fill, no distortion), contain (whole image kept, letterboxed).

Source

.fill   { object-fit: fill; }    /* stretches to fit, can distort   */
.cover  { object-fit: cover; object-position: center; } /* crops, fills frame, no distortion */
.contain{ object-fit: contain; } /* whole image visible, may letterbox */
