CSS Program 28

Em, Rem, Vw, Vh, and Percentage Units

Five text sizes, each defined with a different unit, so you can compare how they scale.

Demo

1.5em — 1.5 × this element's own parent font-size

1.5rem — 1.5 × the root <html> font-size (ignores parent)

5vw — 5% of the current viewport width

5vh — 5% of the current viewport height

150% — 1.5 × the parent's computed font-size, like em

Source

.em  { font-size: 1.5em;  } /* relative to the PARENT element's font-size */
.rem { font-size: 1.5rem; } /* relative to the ROOT (html) font-size, always consistent */
.vw  { font-size: 5vw;    } /* relative to viewport WIDTH  - shrinks/grows with window */
.vh  { font-size: 5vh;    } /* relative to viewport HEIGHT */
.pct { font-size: 150%;   } /* behaves like em, relative to the parent */
