CSS Program 23

Float and Clear Properties

An image floated left with text wrapping around it, and a cleared element that drops below it.

Demo

This paragraph text wraps naturally around the floated image on the left, the way a newspaper column wraps around a picture, because the image has been taken out of normal flow with float:left.

clear: both — this element drops below the float instead of wrapping beside it.

Source

.floated-image{ float: left; margin: 0 1rem 0.5rem 0; }
.text{ /* wraps around the float automatically */ }
.cleared{ clear: both; } /* moves below any floated elements above it */
