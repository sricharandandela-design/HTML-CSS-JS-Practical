Drawer and Slide-out Panel

A panel that slides in from the right edge of the screen, used for filters or detail views.

.slide-panel{
  position:absolute; top:0; right:0; height:100%;
  transform: translateX(100%);  /* hidden past the right edge */
  transition: transform 0.3s ease;
}
.slide-panel.open{ transform: translateX(0); }
