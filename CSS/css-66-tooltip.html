CSS Program 66

Tooltip Component

A pure-CSS tooltip that appears above an element on hover, using the ::after pseudo-element.

Demo

Hover over this text to see its tooltip.

Source

.tt{ position:relative; }
.tt::after{
  content: attr(data-tip);
  position:absolute; bottom:130%; left:50%; transform:translateX(-50%);
  opacity:0; transition:opacity 0.15s ease;
}
.tt:hover::after{ opacity:1; }
