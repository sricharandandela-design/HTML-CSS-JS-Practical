CSS Program 22

Z-index and CSS Stacking Order

Three overlapping boxes; the one with the highest z-index renders on top, regardless of source order.

Demo

z-index: 1
z-index: 3 (on top)
z-index: 2

Source

.back  { position: absolute; z-index: 1; }
.top   { position: absolute; z-index: 3; } /* highest value renders in front */
.middle{ position: absolute; z-index: 2; }
/* z-index only has an effect on positioned elements (not position: static) */
