Responsive SaaS Navigation Menu

The navbar links collapse into a hamburger toggle below 700px — resize the window or view on mobile.

Demo

Flowbase
ProductPricingDocs

Source

.rnav-links{ display:flex; gap:1.2rem; }

@media (max-width:700px){
  .rnav-links{ display:none; flex-direction:column; }   /* hidden by default on mobile */
  .rnav-links.open{ display:flex; }                      /* shown once toggled          */
  .rnav-toggle{ display:block; }                         /* hamburger button appears    */
}
