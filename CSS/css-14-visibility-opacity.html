CSS Program 14

Visibility and Opacity Properties

display:none removes space entirely; visibility:hidden keeps the space; opacity fades without hiding.

Demo

hidden (space kept)

Source

.hidden-but-present{ visibility: hidden; } /* invisible, but still takes up space */
.gone{ display: none; }                     /* invisible AND removed from layout   */
.faded{ opacity: 0.35; }                    /* see-through, still interactive      */
