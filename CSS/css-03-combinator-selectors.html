CSS Program 03

Descendant, Child, Adjacent Sibling, and General Sibling Selectors

Four combinators that relate one selector to another, instead of matching in isolation.

Demo

Direct child of .comb → bold (child combinator).

Heading

Immediately after the heading → green (adjacent sibling).

Any later sibling of the heading → highlighted (general sibling).

  • Nested inside a list → red (descendant combinator).

Source

.comb ul p{ color: red; }        /* descendant  - any depth inside      */
.comb > p{ font-weight: bold; }  /* child       - direct children only  */
.comb h4 + p{ color: green; }    /* adjacent    - the very next sibling  */
.comb h4 ~ span{ background: yellow; } /* general - any later sibling   */
