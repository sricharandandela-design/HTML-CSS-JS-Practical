Margin, Padding, and Spacing Utility Classes

A small set of reusable spacing utility classes, the way many CSS frameworks name them (m-1, p-2, etc.).

Demo

.p-1 (small padding)

Source

.m-1{ margin: 0.25rem; }  .p-1{ padding: 0.25rem; }
.m-2{ margin: 0.5rem;  }  .p-2{ padding: 0.5rem;  }
.m-3{ margin: 1rem;    }  .p-3{ padding: 1rem;    }
/* small, composable classes instead of repeating spacing values everywhere */
