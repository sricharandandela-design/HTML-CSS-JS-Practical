Progress Bar Component

A determinate progress bar showing a percentage, and an indeterminate one for unknown durations.

Demo

Processing (unknown duration)

Source

.progress-bar{ background:#EDEFE9; border-radius:999px; height:10px; overflow:hidden; }
.progress-fill{ height:100%; background:#3F6C5D; width:72%; }  /* set width = percentage */

.indeterminate .progress-fill{ width:40%; animation: move 1.2s ease-in-out infinite; }
@keyframes move{ 0%{ margin-left:-40%; } 100%{ margin-left:100%; } }
