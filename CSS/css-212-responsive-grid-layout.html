Responsive CSS Grid Layout

A grid that automatically fits as many columns as space allows, with no media query needed.

Source

.grid-layout{
  display:grid;
  grid-template-columns: repeat(auto-fit, minmax(120px, 1fr));
  gap:0.8rem;
} /* columns added/removed automatically as width changes */
