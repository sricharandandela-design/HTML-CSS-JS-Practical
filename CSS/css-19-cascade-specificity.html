CSS Program 19

CSS Inheritance, Specificity, and the Cascade

Three rules target the same element; the most specific one wins, and colour is inherited by children automatically.

Demo

span inherits pine colour from its parent .spec-demo

a plain p is red (0-1-1 beats 0-1-0)

p.win is amber (!important overrides everything above)

Source

.spec-demo{ color: teal; }          /* specificity (0,1,0) - inherited by children */
.spec-demo p{ color: red; }         /* specificity (0,1,1) - more specific, wins    */
.spec-demo p.win{ color: orange !important; } /* wins over everything above       */

/* cascade order when specificity ties: later rule in the file wins */
