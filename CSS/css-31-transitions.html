CSS Program 31

CSS Transitions for Colors, Sizes, Shadows, and Positions

Hover over each box to see its property change smoothly instead of snapping instantly.

Demo

hover: colour
hover: size
hover: shadow
hover: position

Source

.box{ transition: all 0.35s ease; } /* animate ANY property that changes */

.box:hover{ background: #E8A33D; }        /* colour transition */
.box:hover{ transform: scale(1.15); }      /* size transition   */
.box:hover{ box-shadow: 0 10px 20px rgba(0,0,0,.35); } /* shadow transition */
.box:hover{ left: 20px; }                 /* position transition (needs position:relative) */
