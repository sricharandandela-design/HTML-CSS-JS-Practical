CSS Program 09

Text Alignment, Decoration, Transformation, Indentation, Spacing, and Line-height

Six text-level properties, each demonstrated on its own paragraph.

Demo

text-align: center

text-decoration: underline wavy

text-transform: uppercase

text-indent: 2rem — notice the first line only.

letter-spacing: 0.15em

line-height: 2 — this paragraph has extra space between its lines so you can see the effect clearly across a longer sentence that wraps.

Source

.center  { text-align: center; }
.wavy    { text-decoration: underline wavy #B14B3F; }
.upper   { text-transform: uppercase; }
.indent  { text-indent: 2rem; }
.spaced  { letter-spacing: 0.15em; }
.airy    { line-height: 2; }
