The CSS Box Model: Content, Padding, Border, and Margin

A single nested-box diagram showing all four layers of the box model at once.

Demo

content

Outer tan layer = margin, dark ring = border, pale layer = padding, green centre = the actual content.

Source

.box{
  margin: 20px;   /* space OUTSIDE the border, transparent   */
  border: 6px solid #1A2332;
  padding: 20px;  /* space INSIDE the border, around content */
  /* the content itself sits inside all of the above */
}
